Implementation Plan for VC User Portal and Admin Enhancements in PTX
Introduction

The PTX project is a portfolio‑wide hiring platform that already exposes a FastAPI backend and a minimal React frontend. The existing code base provides endpoints for authentication and basic CRUD operations on jobs. It also contains polished demo templates in the amis‑talent‑matching repository, such as the demo‑portal.html, which showcase an attractive, dark‑themed jobs page. Our goal is to turn those demos into production features and support a new type of user – VC users (venture capital fund/platform owners) – who have their own job portals.

This plan describes the changes required in the backend (FastAPI), the database (MongoDB), and the React frontend to implement the following features:

Admin portal – admins can log in, list users, create/update/delete users and tenants (VC funds), assign roles and manage each tenant’s job portal.

Registration wizard – a multi‑step form at /registration that replaces the “Create your DEMO account” mock‑up with a real registration process. It creates both the tenant record and the first user (the VC administrator) and returns the unique portal URL.

Unique job portal for every VC user – each tenant gets a portal (similar to the demo‑portal.html) where jobs from their portfolio companies are listed; jobs can be uploaded via CSV by the tenant or an admin. Uploading a new CSV replaces the existing jobs.

Best‑practices data storage – extend the MongoDB schema with a tenants collection, index the relevant fields, and ensure multi‑tenancy isolation.

Provide full code – ready‑to‑copy modules for backend routes, Pydantic models, React pages/components and a CSV template.

2. Database schema changes

To support VC users and per‑tenant portals, extend the MongoDB schema as follows:

tenants collection – each VC organisation/fund is a tenant.

{
  _id: ObjectId,
  name: string,          // name of the fund (e.g., "Venture Capital Partners")
  slug: string,          // unique slug for portal URL (lowercase, URL‑safe, unique index)
  created_at: int,       // UNIX timestamp
  created_by: ObjectId,  // user who created the tenant (admin or self‑registration)
  stats: {               // optional aggregated statistics for dashboards
    job_count: int,
    company_count: int,
    location_count: int
  }
}


Create a unique index on slug to guarantee uniqueness.

users collection changes – add role vc_admin and field tenant_id that references the tenant. Users with role vc_admin can upload jobs for their tenant. Additional roles (recruiter, analyst, candidate) remain unchanged. The admin role remains global.

jobs collection changes – add company_name, application_url and company_website fields. Remove city_canonical (the canonical value can be generated dynamically). Ensure jobs have tenant_id and index (tenant_id, external_job_id) remains as before.

CSV template – the job import will expect a CSV with the following headers:

external_job_id,title,description,city,must_have,nice_to_have,profession,occupation_field,remote,company_name,application_url,company_website
1234,Senior Full‑Stack Engineer,Build next‑generation products,Tel Aviv,"React|Node.js|TypeScript","GraphQL|AWS",Engineering,Software,true,TechFlow AI,,
5678,Product Manager,Lead product development,New York,,,Product,Management,false,DataVision,,


must_have and nice_to_have are pipe‑delimited lists. remote is true or false.

# Utility to generate a URL‑safe slug
_slug_re = re.compile(r'[^a-z0-9]+')
def generate_slug(name: str) -> str:
    base = _slug_re.sub('-', name.lower()).strip('-')
    # ensure uniqueness
    slug = base
    counter = 1
    while db.tenants.find_one({"slug": slug}):
        slug = f"{base}-{counter}"; counter += 1
    return slug

3.2. Registration and tenant creation

Expose a public endpoint to create a tenant and the first user. It returns the portal URL.

@router.post("", response_model=TenantOut)
def create_tenant(payload: TenantCreate):
    # Check if user already exists
    if db.users.find_one({"email": payload.admin_email}):
        raise HTTPException(status_code=409, detail="email_exists")
    # Create tenant
    slug = generate_slug(payload.name)
    tenant_doc = {
        "name": payload.name,
        "slug": slug,
        "created_at": int(time.time()),
    }
    tenant_id = db.tenants.insert_one(tenant_doc).inserted_id
    # Create admin user within the tenant
    user_doc = {
        "name": payload.admin_name,
        "email": payload.admin_email,
        "password_hash": security.hash_password(payload.admin_password),
        "role": "vc_admin",
        "tenant_id": tenant_id,
        "created_at": int(time.time()),
    }
    db.users.insert_one(user_doc)
    return TenantOut(tenant_id=str(tenant_id), slug=slug, name=payload.name)

        raise HTTPException(status_code=409, detail="email_exists")
    if payload.role not in ("admin", "vc_admin", "recruiter", "analyst", "candidate"):
        raise HTTPException(status_code=400, detail="invalid_role")
    tenant_obj = ObjectId(payload.tenant_id) if payload.tenant_id else None

        "name": payload.name,
        "email": payload.email,
        "password_hash": security.hash_password(payload.password),
        "role": payload.role,
        "tenant_id": tenant_obj,
        "created_at": int(time.time()),
    }
    uid = db.users.insert_one(doc).inserted_id
    return {"user_id": str(uid)}

@router.delete("/users/{user_id}", dependencies=[Depends(require_admin)])
def delete_user(user_id: str):
    obj_id = ObjectId(user_id)
    result = db.users.delete_one({"_id": obj_id})
    if result.deleted_count == 0:
        raise HTTPException(status_code=404, detail="user_not_found")
    return {"success": True}

3.4. CSV upload for portfolio jobs

VC admins and global admins can upload a CSV to replace all jobs of a tenant. The endpoint accepts a file and parses it.

from fastapi import status

@router.post("/{tenant_id}/jobs/upload", response_model=CSVImportResponse)
def upload_jobs_csv(tenant_id: str, file: UploadFile = File(...), current_user=Depends(get_current_user)):
    # Only allow if current user is admin or vc_admin of this tenant
    if current_user["role"] not in ("admin", "vc_admin"):
        raise HTTPException(status_code=403, detail="forbidden")
    if current_user["role"] == "vc_admin" and str(current_user.get("tenant_id")) != tenant_id:
        raise HTTPException(status_code=403, detail="wrong_tenant")
    # Read CSV
    content = await file.read()
    reader = csv.DictReader(io.StringIO(content.decode()))
    jobs = []
    required = ["external_job_id", "title", "description"]
    for row in reader:
        if not all(row.get(k) for k in required):
            continue  # skip incomplete rows
        must = [s.strip().lower() for s in row.get("must_have", "").split("|") if s.strip()]
        nice = [s.strip().lower() for s in row.get("nice_to_have", "").split("|") if s.strip()]
        merged = list(dict.fromkeys(must + nice))  # unique order preserving
        jobs.append({
            "tenant_id": ObjectId(tenant_id),
            "external_job_id": row["external_job_id"],
            "title": row["title"],
            "job_description": row["description"],
            "city": row.get("city"),
            "requirements": {
                "must_have_skills": [{"name": s} for s in must],
                "nice_to_have_skills": [{"name": s} for s in nice],
            },
            "job_requirements": must + nice,
            "skill_set": merged,
            "profession": row.get("profession"),
            "occupation_field": row.get("occupation_field"),
            "remote": row.get("remote", "false").lower() == "true",
            "company_name": row.get("company_name"),
            "application_url": row.get("application_url"),
            "company_website": row.get("company_website"),
            "created_at": int(time.time()),
            "updated_at": int(time.time()),
        })
    # Replace existing jobs for tenant
    replaced = db.jobs.delete_many({"tenant_id": ObjectId(tenant_id)}).deleted_count
    if jobs:
        db.jobs.insert_many(jobs)
    return CSVImportResponse(inserted_count=len(jobs), replaced_count=replaced)

3.5. Public portal endpoint

A public, unauthenticated endpoint returns the tenant’s metadata and jobs for use in the portal UI. It searches by slug.

@router.get("/public/portal/{slug}")
def get_public_portal(slug: str):
    tenant = db.tenants.find_one({"slug": slug})
    if not tenant:
        raise HTTPException(status_code=404, detail="portal_not_found")
    t_id = tenant["_id"]
    jobs = []
    for j in db.jobs.find({"tenant_id": t_id}).sort("created_at", -1):
        jobs.append({
            "job_id": str(j["_id"]),
            "title": j.get("title"),
            "company_name": j.get("company_name", ""),
            "description": j.get("job_description", ""),
            "requirements": j.get("skill_set", []),
            "location": j.get("city", "Remote"),
            "remote": j.get("remote", False),
            "application_url": j.get("application_url"),
            "company_website": j.get("company_website"),
        })
    return {
        "name": tenant["name"],
        "slug": tenant["slug"],
        "stats": {
            "job_count": len(jobs),
            "company_count": len({j["company_name"] for j in jobs if j["company_name"]}),
            "location_count": len({j["location"] for j in jobs}),
        },
        "jobs": jobs,
    }

export async function apiPost(path: string, body: any) {
  const token = localStorage.getItem('token')
  const res = await fetch(`${API_BASE}${path}`, {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      ...(token ? { Authorization: `Bearer ${token}` } : {}),
    },
    body: JSON.stringify(body),
  })
  if (!res.ok) throw new Error(await res.text())
  return res.json()
}

export async function apiUpload(path: string, file: File) {
  const token = localStorage.getItem('token')
  const formData = new FormData()
  formData.append('file', file)
  const res = await fetch(`${API_BASE}${path}`, {
    method: 'POST',
    headers: { ...(token ? { Authorization: `Bearer ${token}` } : {}) },
    body: formData,
  })
  if (!res.ok) throw new Error(await res.text())
  return res.json()
}

import React, { useState } from 'react'

                </div>
                <button style={{ marginTop: 'auto', background: 'linear-gradient(135deg,#10b981,#06b6d4)', color: '#fff', border: 'none', borderRadius: 10, padding: '12px 20px', fontSize: 14, fontWeight: 600, cursor: 'pointer' }} onClick={() => {
                  const url = job.application_url || job.company_website || ''
                  if (url) window.open(url, '_blank')
                }}>Apply Now →</button>
              </div>
            ))}
            {jobs.length === 0 && <div style={{ gridColumn: '1 / -1', textAlign: 'center', padding: 40, color: '#94a3b8' }}>No positions found</div>}
          </div>
        </section>
      </main>
      <footer style={{ borderTop: '1px solid #1f2937', padding: '40px 0', textAlign: 'center', color: '#94a3b8', fontSize: 14 }}>
        Powered by PTX • Portfolio Talent Exchange
      </footer>
    </div>
  )
